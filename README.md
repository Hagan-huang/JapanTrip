# 京都・大阪 9 天 8 夜｜2027.1.13–1.21

👉 網址：**https://hagan-huang.github.io/JapanTrip/**

旅行網頁（預設墨色風格，可切換昭和／霓虹）：航班、每日行程、出發前準備、記帳（個人帳＋分帳），加上在日本當地用的工具箱。

---

## 給團員：怎麼用

### 1. 加到主畫面（建議）
iPhone：用 Safari 打開網址 → 下方「分享」⬆ →「加入主畫面」。
之後從桌面的「KANSAI 2027」圖示打開，全螢幕、沒網路也看得到行程。

### 2. 登入
在「航班」或「記帳」頁輸入三樣東西：
- **暱稱**：大家看到的名字
- **個人密碼**：4–12 字，自己記得就好（換手機時要用）
- **團體密碼**：問 Hagan

第一次輸入就是建立帳號。換手機時輸入同樣的暱稱和個人密碼，個人帳、清單和設定都會回來。

### 3. 登記你的航班
「航班」頁最上面點你搭的那班，名字會出現在那班的乘客欄。
行程頁也會自動切到你那組（京都組／1/15 大阪組／1/16 大阪組）。

### 4. 記帳
- **個人**：只有自己看得到
- **分帳**：選誰付的、分給誰，「團體分帳」會算出誰該轉多少給誰
- 沒網路時記的分帳會先存在手機，連上網自動上傳

### 5. 旅行當天
- **行程頁**：自動跳到今天，標出「進行中」「下一個」，走過的會變淡；有關門時間的會倒數（剩 45 分鐘內變紅）。點景點直接用 Google 地圖導航（大眾運輸）。
- **分享某一天**：行程卡右上角的分享鈕，傳到 LINE 群組，對方點開就是那天。
- **主頁工具箱**：回住宿（自動挑今晚住的地方）、給司機看、日文會話卡、緊急求助、旅遊須知。
- 沒網路時上方會提示，行程、住宿、會話卡、緊急電話都照樣能看。

### 6. 給司機看
「準備」頁的「🚕 給司機看」，點了把手機拿給計程車司機看日文地址。

## 給管理者（Hagan）

### 改行程：直接改 Google 試算表
試算表裡有兩個分頁，改完重新整理網頁就會更新：

**「每日」**：每天的標題、住宿、人數

**「行程」**：每一個行程項目，一列一項

| 欄位 | 怎麼填 |
| --- | --- |
| 日期 | `1/13` 這種格式 |
| 時間 | `09:30`，或「上午」「下午」「晚上」「—」；同一天會照時間自動排序 |
| 類型 | 下拉選：交通／景點／吃／提醒 |
| 交通 | 下拉選：地鐵、JR、京阪…（類型是交通才需要） |
| 內容 | 主要文字（必填，空白的列會被忽略） |
| 備註 | 小字說明 |
| 時間提醒 | 粉紅色的提醒，例如「17:00 關門」 |
| 地圖搜尋 | 填了就會出現 MAP 按鈕，內容是 Google Maps 搜尋關鍵字 |
| 待定 | 打勾會用虛線框顯示 |
| 組別 | 空白＝這天的預設組別；只給某組看就填「京都組」「1/15 大阪組」「1/16 大阪組」，多組用頓號隔開 |
| 人數標籤 | 黃色小標籤，例如「8 人」 |

> 新增一列就是新增一個行程；刪掉那一列就是刪除。

### 其他資料：`data.js`
航班、住宿、待辦預設清單、圖片設定都在 `data.js`。需要改的話找 Claude。

### 共用帳本（Google Apps Script）
程式在 `apps-script/Code.gs`。**2026-11-13 這版有資安修正，一定要更新**（分帳紀錄改成要團體密碼才能讀、刪改分帳要驗證個人密碼、密碼錯 8 次鎖 15 分鐘、行程覆寫前自動備份到「行程備份」分頁）。沒更新的話網站還是能用，只是這些保護不會生效。更新方式：
1. 試算表 →「擴充功能」→「Apps Script」，全部換成新版程式
2. **第 7 行重新填團體密碼**
3. 「部署」→「管理部署作業」→ 鉛筆 →「版本」選「新版本」→「部署」（網址不會變）

試算表分頁：成員、分帳紀錄、個人資料、每日、行程、行程備份。

> 行程以試算表為準。`data.js` 的 `ITIN_PATCHES` 會把整天覆寫進試算表，覆寫前的舊資料會存在「行程備份」分頁；手動在試算表改過的日子，之後就不要再用 patch 改同一天。

### 資安與隱私
- 網站和 GitHub repo 是公開的：`data.js` 裡的航班、住宿地址任何人都看得到（已經加上 noindex，不會被 Google 收錄）。
- 分帳、成員、個人帳存在 Google 試算表，要團體密碼＋個人密碼才讀得到。團體密碼只填在 Apps Script，**不要寫進 GitHub 的檔案**。
